# Judging Criteria

1. Problem fit and impact (30%) — does it solve a real, painful problem for a
   clearly identified user, and is the value demonstrable?
2. Technical depth (25%) — is the AI/ML work credible, evaluated, and more than
   a thin wrapper around an API?
3. Demo quality (20%) — does it work live, reliably, and tell a clear story?
4. Innovation and differentiation (15%) — is there a real insight here?
5. Documentation and reproducibility (10%) — can a judge run it from the repo?
